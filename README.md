# Өз қадамым

Дефектологқа арналған демо қосымша: оқушылар (тек ойдан шығарылған кодтар), сабақ жоспары, журнал және ата-анаға есеп.

## Іске қосу

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # dist/ қалтасына жинау
```

## Логикасы

**Мұғалім** (құпиясөзбен кіреді):
1. **Оқушылар** — аты-жөні, диагнозы/ерекшелігі, ескертпе, ата-ана PIN коды.
2. **ҚМЖ бейімдеу** — кез келген ҚМЖ жүктеледі (TXT/DOCX), Claude оны әр оқушының диагнозына қарай өте жеңіл 2–3 ойынға айналдырады: математикада пішіндер мен санау, қазақ тілінде дыбысты тыңдау, шашылған әріптерден сөз құрау, бос орынды толтыру. «Дауыстау» батырмасы ElevenLabs арқылы барлық нұсқауды апайдың дауысымен жазып қояды.
3. **Ілгерілеу** — оқушы ойынды аяқтаған сайын нәтиже өзі түседі, шолу автоматты түрде жаңарады; мұғалім сурет/жазба қосып, ата-анаға жариялайды.
4. **Ата-анаға есеп** — бір ортақ сілтеме (`/parent`) және әр оқушының PIN коды.

**Оқушы** — `/play/<id>` сілтемесі арқылы планшетте ойнайды (кіру қажет емес).

**Ата-ана** — `/parent` сілтемесінде бір рет баласын таңдап, PIN енгізеді; содан кейін тек өз баласының шолуын, жарияланған суреттерін, нәтижелерін көреді және бот (Claude) тек сол деректерге сүйеніп жауап береді.

## Құрылымы

- `src/` — React (Vite, TanStack Router, Tailwind v4)
- `api/` — Vercel серверлік функциялары: `teacher.ts`, `play.ts`, `parent.ts`
- Дерекқор және суреттер/дыбыстар: Supabase (`media` жабық бакеті)
- Кілттер: `.env.example` қараңыз. Кілттер қосылмаса, сайт демо режимде жұмыс істейді (деректер уақытша).

Балалардың аты мен диагнозы кодта сақталмайды, тек дерекқорда.

## Vercel

Репоны импорттаңыз (Framework — Vite). Settings → Environment Variables ішіне `.env.example`-дегі айнымалыларды қосып, Redeploy басыңыз.
