# Өз қадамым

Дефектологқа арналған демо қосымша: оқушылар (тек ойдан шығарылған кодтар), сабақ жоспары, журнал және ата-анаға есеп.

## Іске қосу

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # dist/ қалтасына жинау
```

## Логикасы

Барлық дерек `src/lib/store.tsx` ішіндегі бір қоймада, браузердің localStorage-інде сақталады (серверсіз).

1. **Оқушылар** (`/profiles`) — код, мақсат, қолдау түрлері, «таңдалған» белгісі.
2. **Сабақ жоспары** (`/lesson`) — TXT/DOCX жүктеу, мәтін қою немесе мақсатқа сай үлгі; содан кейін бекіту.
3. **Журнал** (`/journal`) — тапсырма нәтижесі: өз бетімен / көмекпен / әзірге жоқ.
4. **Есептер** (`/reports`) — журнал жазбасынан ата-анаға мәтін жасалады, мұғалім өңдеп бекітеді → «Кезекте».

Басты бет (`/`) осы деректерден көрсеткіштерді және әр оқушының соңғы 7 күндегі «өз бетімен» пайызын (`weeklySummary`) есептейді.

Стек: Vite, React 19, TanStack Router (файлдық маршруттар), Tailwind CSS v4.

## Vercel

Vercel-де жаңа жоба ретінде осы репоны импорттаңыз: Framework — Vite, Build — `npm run build`, Output — `dist`. `vercel.json` барлық беттерді `index.html`-ге бағыттайды, сондықтан `/lesson` сияқты сілтемелер тікелей ашылады.
